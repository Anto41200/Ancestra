Configuration Supabase

Supabase est gratuit et permet la sync multi-appareils. Suivez ces étapes :

1
Allez sur supabase.com → créez un compte gratuit → New Project
2
Dans Project Settings → API, copiez l'URL et l'anon public key
3
Dans SQL Editor, exécutez ce script pour créer la table :
CREATE TABLE family_trees (
  id uuid DEFAULT gen_random_uuid() PRIMARY KEY,
  user_id uuid REFERENCES auth.users NOT NULL,
  data jsonb NOT NULL,
  updated_at timestamptz DEFAULT now()
);
ALTER TABLE family_trees ENABLE ROW LEVEL SECURITY;
CREATE POLICY "Users own their tree" ON family_trees
  USING (auth.uid() = user_id)
  WITH CHECK (auth.uid() = user_id);
4
Dans index.html ET app.html, remplacez VOTRE_URL et VOTRE_ANON_KEY en haut du JS
